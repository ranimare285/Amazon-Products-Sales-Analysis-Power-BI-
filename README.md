# Amazon-Products-Sales-Analysis-Power-BI-

## Project Overview

This project showcases an end-to-end sales analysis dashboard built using Power BI to analyze Amazon product sales data. The dashboard helps identify sales trends, category performance, top products, and customer engagement using interactive and visually rich reports.

## Business Objectives

* Analyze Year-to-Date (YTD) and Quarter-to-Date (QTD) sales performance
* Identify top-performing product categories and products
* Track monthly and weekly sales trends
* Understand customer interest through product reviews

 ## Skills & Tools Used

* Power BI Desktop
* DAX (Calculated Measures & KPIs)
* Data Modeling
* Data Cleaning & Transformation
* Interactive Dashboard Design

## Key Insights Delivered

* $2.18M YTD Sales and $811K QTD Sales performance tracking
* Clear visibility into sales growth by product category
* Identification of Top 5 products by sales and reviews
* Seasonal spikes detected through monthly and weekly trend analysis

## Dashboard Features

* KPI cards for Sales, Products Sold, and Reviews
* Category-wise sales table with growth contribution
* Monthly & Weekly sales trend analysis
* Top 5 Products by Sales and Customer Reviews
* Interactive slicers for dynamic data exploration

## How to Run the Project

* Download the .pbix file from this repository
* Open it using Power BI Desktop
* Use filters such as Product Category and Order Date
* Explore insights by interacting with visuals
